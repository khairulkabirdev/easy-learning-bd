  components/admin/ModelQuestionSetEditor.tsx

  app/admin/model-question-import/[classId]/[subjectId]/[setId]/page.tsx

HOW IT WORKS
- In Class 6 and Class 7, subject English / English 1st Paper, Add Content
  Block uses the existing curriculum editor's grouped picker:

  Seen — Passage 1:
  1. Passage 1; 2. MCQ; 3. Answering Questions

  Seen — Passage 2:
  4. Passage 2; 5. Information Transfer; 6. True / False

  Other Reading Questions:
  7. Fill in the Blanks; 8. Table Completion; 9. Rearrange Sentence

- The old standalone picker no longer appears in this model-question flow.
- Clicking Add Content Block in Previous question blocks & TXT/JSON import
  opens the same native grouped picker instead of creating incompatible copies.
- Each click on a block type creates an independent block; the same type may be
  added repeatedly, using the existing ContentBlock create action and editors.
- Older TXT/JSON-imported question records remain editable and are not converted.
- Other class/subject menus keep their existing choices.

DATA SAFETY
This package changes UI files only. It contains NO database files, SQL,
Prisma schema, migration, API route, uploaded files, or environment files.
No database reset, reseeding, or schema commands are required.

STEPS
1. Stop the Next.js development server.
2. Back up the three existing TSX files before replacing or merging.
3. Extract this ZIP at the project root (not inside an extra folder).
4. Start the existing development server: npm run dev
5. Open the Model Question detail route and click Add Content Block.
